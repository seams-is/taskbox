# Saved days, for calibrating the simulator

Each `*.json` here is one day of the box's own jobs: `taskbox job list --all --json` typed as remote, or a load test's `day` session from `taskbox load report --session N --replay`, which keeps each job's `vmKind`, `className`, `jobAt`, `endedAt`, `phases` and peak, and names no job, repo or run. `test/acceptance.test.ts` replays each one with that day's measured boot times and checks that the simulator's waits match the box's within 3 min, and that the acceptance criteria come out the same. A day where they don't is a fix to the simulator before any fix to the rules.
